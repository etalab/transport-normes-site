**OpRa** est un format d'échange normalisé permettant de décrire les données opérationnelles historiques de transport public.

Il n'existe pas pour le moment de profil français d'OpRa, mais le format peut déjà être mobilisé pour publier les données conformément à la réglementation en vigueur.

NeTEx, SIRI et OpRa sont des formats dérivés de **Transmodel** : il s'agit d'un modèle conceptuel de données qui a pour objectif de définir un vocabulaire commun pour l'échange de données structurées de transport public.
