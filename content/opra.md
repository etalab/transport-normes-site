**OpRa** (<span lang="en">Operating raw data</span>) est un format d'échange permettant de décrire les données opérationnelles historisées et statistiques d'une offre de transport public. C'est une norme, publiée par le CEN (comité européen de normalisation) sous la référence [CEN/TS 17370](https://transmodel-cen.eu/index.php/opra/).

En complément des documents de spécification technique, OpRa fournit également un schéma W3C XML (XSD) qui peut être utilisé directement par les logiciels produisant, validant et utilisant les données. Ce schéma est disponible sur [l'espace de travail Github](https://github.com/TransmodelEcosystem/OpRa) du projet, géré par le CEN.

OpRa, comme SIRI et NeTEx, est un format dérivé de **[Transmodel]()** : il s'agit d'un modèle conceptuel de données qui a pour objectif de définir un vocabulaire commun pour l'échange de données structurées de transport public.

## Profil français

Il n'existe pas à ce jour de profil France pour OpRa.

La norme européenne peut cependant déjà être utilisée pour exporter des données opérationnelles dans le contexte français.

## Questions fréquentes

<details>
<summary>Que peut-on représenter avec OpRa ?</summary>

OpRa permet de décrire la réalité observée de l'exploitation, comme les retards ou les annulations de trajets.

OpRa permet de représenter les données soit sous la forme de mesures individuelles sur un intervalle donné, soit de manière agrégée sous la forme de statistiques.
