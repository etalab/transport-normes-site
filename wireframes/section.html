Avant-propos

Le présent document décrit le profil France de NeTEx relatif aux données d'arrêts. Il définit les champs et contraintes applicables à la description des points d'arrêt du réseau de transport.

L'harmonisation des pratiques dans l'échange des données relatives aux offres de transport est essentielle :

  • Pour l'usager, aux fins d'une présentation homogène et compréhensible de l'offre de transport ;
  • Pour les autorités organisatrices, de manière à fédérer des informations homogènes venant de chacun des opérateurs ;
  • Pour les opérateurs, qui pourront utiliser ce format d'échange pour leurs systèmes d'information voyageur.

Champ ArretType

Le type ArretType définit un point d'arrêt de transport en commun. Il contient les informations suivantes :

Éléments du type ArretType
Champ Type Occurrence Description
id ResourceIdType 1..1 Identifiant unique de l'arrêt
name TextParameterType 1..1 Nom commercial de l'arrêt
publicCode TextParameterType 0..1 Code public d'identification (ex: nom de station)
centralName SiteRef 1..1 Référence au site d'arrêt central
accessibilityAssessment AccessibilityAssessmentStructure 0..1 Évaluation de l'accessibilité du point d'arrêt

Champ ÉquipementArretType

Définit les équipements disponibles à un point d'arrêt (abribus, horodateur, éclairage, etc.).
